English Note Specimen SQL Windowing

PARTITION BY Clause

"The PARTITION BY clause divides the query result set into partitions to which the analytical function is applied independently. Unlike GROUP BY, it does not collapse the output rows."

SELECT emp_id, dept_id, salary,
  AVG(salary) OVER(
    PARTITION BY dept_id
  ) as dept_avg
FROM employees;
Hinglish Note Specimen Concept Simplified

PARTITION BY Kaise Kaam Karta Hai

"PARTITION BY table ke rows ko logical groups mein divide karta hai. Main difference yeh hai ki GROUP BY rows ko merge karke single row bana deta hai, par yahan har employee row intact rehti hai."

Exam Tip: Jab bhi output mein individual details aur department averages dono ek saath chahiye hon, hamesha Window Function use karo.
